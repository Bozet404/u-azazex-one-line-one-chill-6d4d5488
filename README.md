## The entry

One original horror sentence, 104 characters, written to scare a reader in a single breath:

> The dentist found a second set of teeth growing behind mine, and this morning they were already chewing.

## How it works

`main.py` writes that single sentence to `/output/entry.txt`. It checks the
line first — one sentence, one line, 1–200 characters — and refuses to write
anything that would fail the gate.

Run it with:

```sh
python3 main.py
```
